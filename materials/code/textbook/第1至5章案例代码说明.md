# 第1—5章案例代码说明

第1—5章现在各保留一个课堂主案例。学生只需运行下列主脚本：

| 章节 | Python | Stata |
|---|---|---|
| 第1章 | `python/ch01/01_monte_carlo_foundations.py` | `stata/ch01/01_monte_carlo_foundations.do` |
| 第2章 | `python/ch02/01_controls_ovb.py` | `stata/ch02/01_controls_ovb.do` |
| 第3章 | `python/ch03/01_read_regression_table.py` | `stata/ch03/01_read_regression_table.do` |
| 第4章 | `python/ch04/01_wage_form_specification.py` | `stata/ch04/01_wage_form_specification.do` |
| 第5章 | `python/ch05/01_model_diagnostics.py` | `stata/ch05/01_model_diagnostics.do` |

第1章另有一个生成引例图的脚本：`python/ch01/00_ai_score_scatter.py`（图1-1、图1-2、图1-4）。

各章`legacy/`目录保存修订前的旧脚本，仅供教师追溯或作为拓展实验，不属于课堂必做内容。第3章旧的第一类错误和第二类错误模拟也保存在该目录中。

Python和Stata两套主脚本均已实际运行验证。Stata版在StataNow 19.5 MP中批处理运行，各章的`output/`目录保存对应图形，日志均正常结束。Stata脚本与Python脚本使用相同的数据生成逻辑和分析任务；两种软件的随机数算法不同，具体数值不要求完全一致。

# 第2章 Agent任务卡：控制变量、遗漏变量与FWL

## 目标

在同一份工资数据中比较遗漏模型和完整模型，并用FWL三步法重新得到教育系数。

## 工作顺序

1. 只读检查工资数据的生成关系和完整模型假设。
2. 确认遗漏模型与完整模型使用同一批观测。
3. 运行代码，保存模型比较结果和FWL三联图。
4. 核对完整回归教育系数与残差回归斜率是否一致。
5. 将偏误方向判断、数值核对和解释边界写入`ai_log.md`。

## 必须核验

- 两次残差化必须使用相同控制变量并包含常数项；
- 偏误方向取决于遗漏变量对工资的影响及其与教育的相关方向；
- FWL是样本代数分解，不是因果识别证明；
- 本案例破坏的是零条件均值，不是同方差条件。

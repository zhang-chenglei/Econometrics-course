# 第3章 Agent任务卡：读懂一张回归表

## 目标

围绕一张工资回归表完成结构识别、单个系数推断、联合检验和论文式表述。

## 工作顺序

1. 只读检查因变量、解释变量、样本量和估计方法。
2. 经确认后运行代码并保存回归表与95%置信区间图。
3. 选择教育系数，重新计算$t$值并核对置信区间。
4. 核对“经验和任职年限系数同时为0”的联合检验。
5. 起草一段结果解释，由学习者检查经济含义和因果边界。

## 必须核验

- 系数、标准误、$t$值、$p$值和置信区间之间应相互一致；
- 星号不能代替系数大小和置信区间；
- 联合显著不等于每个变量都单独显著；
- 显著的条件相关不能自动解释为因果效应。

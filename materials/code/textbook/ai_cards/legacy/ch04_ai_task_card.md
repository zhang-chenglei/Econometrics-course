# 第4章 AI Agent任务卡：模型形式、非线性与异质性

## 一、任务目标

在同一份合成工资数据中比较水平模型、对数模型、二次项模型和交互项模型，理解不同函数形式回答的问题、系数单位以及预测和边际效应的正确计算方法。

## 二、项目要求与结构

建立包含 `README.md`、`code/`、`results/figures/`、`results/tables/`、`logs/` 和 `ai_log.md` 的 `chapter04_project/`。README应说明四个模型的因变量、解释变量、基准组、系数单位和运行顺序。代码必须保存模型比较表、调整后的二次拟合图、群体教育回报表和日志。

## 三、分析任务

1. 比较工资水平模型与对数工资模型，分别解释教育系数；
2. 加入经验平方项，计算边际效应和极值点，并检查极值点是否位于样本范围；
3. 加入教育与性别、城乡的交互项，计算四个群体的教育回报及其不确定性；
4. 根据研究问题比较模型，而不是比较不可直接对照的 \(R^2\)。

预测图所使用的变量顺序和常数项必须与估计模型完全一致；交互项的组间差异应通过线性组合或直接检验得到。

## 四、AI Agent工作流与判断边界

使用Agent前，先写出四种模型中目标系数的单位和预期解释。然后让Agent只读检查任务卡与配套脚本，列出四个模型的因变量、新增项、基准组、运行顺序和输出。确认后运行程序，并用手工计算或软件的边际效应命令核对关键数值。

可以让Agent检查对数系数、二次项和交互项的计算，核对预测数据列与模型是否一致。例如：

> 请逐项核对预测矩阵与回归模型的变量名称和顺序，避免图形使用错误预测值。

> 请检查四个群体的教育回报是否由正确的系数组合得到，并同时计算标准误。

Agent运行后必须报告生成的模型表、预测图和群体效应表，并说明是否修改过代码。必须由你自己判断极值点是否有经济意义、模型形式是否符合研究问题，以及群体差异能否作因果解释。模型更复杂或 \(R^2\) 更高都不是自动选择依据。

## 五、提交前检查

- 四个模型均可从头运行并生成结果；
- 水平模型和对数模型的系数没有混用；
- 二次拟合图使用与回归一致的控制变量设定；
- 四个群体的线性组合和差异检验正确；
- README能够说明每个模型适合回答什么问题。

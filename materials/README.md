# 代码与教学数据

## 学生下载请去这里

供学生使用的代码与数据统一放在独立仓库：

**<https://github.com/zhang-chenglei/Econometrics-course-materials>**

那里按教材章节组织，点进任一章即见该章的 `python/`、`stata/` 与 `AI任务卡.md`，
另有第11—14章综合案例与 `数据/`。下载 ZIP 后可直接运行，不需要改路径。

## 本目录

本目录只保留课程网站自身需要随站发布的材料：

- `data/`：教学数据，供 `course/materials.qmd` 的直链下载使用
  - `semisynthetic/`：匿名半合成企业面板与变量说明
  - `policy/`：人工智能试验区公开政策事实与处理时间编码
- `slides/`：课堂讲义文件

代码不放在这里。原先的 `materials/code/` 已移出，学生所需内容全部在
上面那个仓库；维护者请在 EconKB `30_教学/09_计量教材/code/` 改源文件，
再由课程网站仓库的 `tools/sync_student_repo.py` 同步到学生仓库。

## 数据声明

半合成企业样本仅用于计量经济学方法教学，不能用于判断现实政策效果。政策批复信息来自公开政府文件。本站不公开包含真实企业标识的内部母表、原始年鉴或受数据库许可约束的材料。
